# Calculator Project


## What it does
A working calculator built with Java Swing.
Supports addition, subtraction, multiplication, division,
backspace, percent, sign toggle, and decimal input.


## How to run it
1. Open CMD
2. cd to the project folder
3. javac Calculator*.java
4. java CalculatorController
